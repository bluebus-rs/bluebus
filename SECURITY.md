# Security policy

## Supported versions

Security fixes go into the latest release of the `bluebus` crate.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub security advisories](https://github.com/bluebus-rs/bluebus/security/advisories/new).
Include the bluebus and BlueZ versions and a way to reproduce it.

You should get a reply within a week. Once a fix is released, the advisory
is published with credit to the reporter, unless you prefer otherwise.
